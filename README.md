# E-commerce Sales & Profitability Analysis using MySQL

## 📌 Project Overview
Analyzed 138k+ E-commerce orders to identify sales trends, top profitable products, loss-making categories, and customer behavior. This project simulates a real business case for a Data Analyst role.

## 🛠️ Tools & Technologies
- MySQL Workbench
- SQL (Joins, Aggregation, Window Functions, Subqueries)

## 📂 Dataset
- Table: E-commerce Orders (138k+ Rows)
- Columns: Order_ID, Product, Category, Sales, Profit, Discount, Region etc.

## 🔍 Key Analysis Performed
1.  **Overall Sales Report:** Total Sales, Profit, and Quantity sold.
2.  **Top 10 Profitable Products:** Found which products generate max profit.
3.  **Loss-Making Products:** Identified products with negative profit due to high discounts.
4.  **Category-wise Performance:** Compared Technology vs Furniture vs Office Supplies.
5.  **Regional Analysis:** Which region is driving max sales.
